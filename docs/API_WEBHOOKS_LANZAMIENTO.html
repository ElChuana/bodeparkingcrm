Integración de Webhooks — Lanzamiento

Recepción de contactos del lanzamiento en el CRM de BodeParking
Dirección del flujo: ustedes emiten (outbound) → BodeParking recibe (inbound)
Resumen

Un solo endpoint, dos eventos distinguidos por el campo estado: cuando el prospecto rellena el formulario (estado: "formulario-rellenado") y cuando agenda la cita tipo Calendly (estado: "agenda"). El CRM crea/actualiza el contacto, evita duplicados, en el caso de agenda deja la reunión en el calendario, y notifica al ejecutivo de ventas.

Convenciones generales

Método y formato
POSTTodos los webhooks usan POST.
Content-Typeapplication/json; charset=utf-8
Respuesta esperadaEl CRM responde 2xx al recibir correctamente (201 creado / 200 ya existía).
Autenticación

Cada request debe incluir la API Key en el header:

HEADER X-Api-Key: bp_62149ad6d81bc708b3f57542ac43f13c140607e436782e72
La API Key se las entrega BodeParking. Si falta o es inválida, el CRM responde 401.
URL base
BASE https://backend-production-1c52.up.railway.app

Endpoint

Un mismo endpoint recibe los dos eventos. Se diferencian por el campo estado.
POST https://backend-production-1c52.up.railway.app/api/public/webhooks/webinar

1Formulario rellenado

El prospecto completa el formulario / reserva, sin agendar cita. estado: "formulario-rellenado"
Cuerpo (JSON)
{
  "nombre": "María González",
  "correo": "maria.gonzalez@email.com",
  "telefono": "+56912345678",
  "estado": "formulario-rellenado"
}
Respuesta
{ "ok": true, "evento": "formulario", "duplicado": false, "leadId": 1234, "etapa": "NUEVO" }

Crea el lead en etapa NUEVO (campaña "Webinar"). Si el contacto ya existía, responde duplicado: true y no crea otro.

2Cita agendada → calendario

El prospecto agenda la cita de asesoría / reunión comercial (tipo Calendly). estado: "agenda"
Cuerpo (JSON)
{
  "nombre": "María González",
  "correo": "maria.gonzalez@email.com",
  "telefono": "+56912345678",
  "estado": "agenda",
  "inicio": "2026-06-12T16:30:00",   // fecha/hora de la cita (hora de Chile)
  "enlace": "https://meet.google.com/abc-defg-hij"   // opcional: link del Meet/Zoom
}
La fecha/hora se puede enviar de dos formas (usar una):
• "inicio" en formato ISO 8601 — recomendado, es lo que entrega Calendly (ej: "2026-06-12T20:30:00Z" o con offset "2026-06-12T16:30:00-04:00").
• o por separado: "fecha": "12/06/2026" + "hora": "16:30".
Zona horaria: la hora se interpreta siempre como hora de Chile (las citas son con clientes en Chile). Envíen la hora que el cliente eligió en horario chileno; la marca de zona del ISO (Z u offset) se ignora.
Respuesta
{
  "ok": true,
  "evento": "agenda",
  "leadId": 1234,
  "visitaId": 56,
  "enCalendario": true,
  "fechaHora": "2026-06-12T16:30:00.000Z"
}

Agenda la reunión como visita en el calendario, mueve el lead a VISITA_AGENDADA y notifica al ejecutivo (con recordatorio automático 24 h antes). Si llega sin fecha/hora, igual agenda el lead y avisa para coordinar.

Campos

CampoTipoNotas
nombrestringrequeridoNombre completo del contacto ("Nombre Apellido").
correostringopcionalEmail del contacto (también se acepta email).
telefonostringopcionalFormato internacional (+569…).
estadostringrequeridoformulario-rellenado o agenda. Determina qué hace el CRM.
iniciostringsolo agendaFecha/hora de la cita en ISO 8601. Alternativa: fecha + hora.
fecha / horastringsolo agenda"DD/MM/YYYY" y "HH:MM" (si no se usa inicio).
enlacestringsolo agendaLink de la reunión online (Meet/Zoom). También se acepta meetUrl / link.
Se recomienda enviar correo o teléfono (idealmente ambos): el CRM los usa para evitar contactos duplicados.

Comportamiento del CRM

Anti-duplicadosSi el contacto ya existe (por correo o teléfono + nombre similar), se reutiliza; no se crean duplicados.
Reenvío idempotenteReenviar el mismo evento de agenda (mismo contacto + misma fecha/hora) no duplica la reunión.
NotificaciónEl ejecutivo de ventas y la gerencia reciben aviso al instante; recordatorio automático 24 h antes de la cita.
Sin fechaSi el webhook de agenda llega sin fecha/hora, el lead queda agendado y se notifica para coordinar la hora manualmente.

Ejemplo (cURL)

curl -X POST https://backend-production-1c52.up.railway.app/api/public/webhooks/webinar \
  -H "Content-Type: application/json" \
  -H "X-Api-Key: bp_62149ad6d81bc708b3f57542ac43f13c140607e436782e72" \
  -d '{
    "nombre": "María González",
    "correo": "maria.gonzalez@email.com",
    "telefono": "+56912345678",
    "estado": "agenda",
    "inicio": "2026-06-12T16:30:00"
  }'
