---
name: feedback_no_code_until_told
description: No escribir código hasta que el usuario lo indique explícitamente
type: feedback
---

No escribir ningún código hasta que el usuario diga explícitamente que está listo para comenzar.

**Why:** El usuario quiere planear completamente antes de codificar. Prefiere hacer todas las preguntas necesarias primero.

**How to apply:** En cada conversación sobre este proyecto, solo diseñar, preguntar y documentar hasta recibir la señal explícita de "escribe el código" o similar.
