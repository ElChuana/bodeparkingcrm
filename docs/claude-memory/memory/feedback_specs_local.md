No commitear specs ni docs de diseño a git. Dejarlos como archivos locales únicamente.

**Why:** El usuario no quiere que los specs de diseño queden en el historial de git de producción.

**How to apply:** Después de escribir un spec en docs/superpowers/specs/, NO hacer git add ni git commit de ese archivo.
