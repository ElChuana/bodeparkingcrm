Paleta oficial de BodeParking (fuente: PDF "Colores y codigos.pdf"):

| Color | Hex | Uso |
|-------|-----|-----|
| Azul principal | `#0091c3` | Color primario, CTAs, headers |
| Gris oscuro | `#3d3d3d` | Textos, logo wordmark |
| Blanco | `#ffffff` | Fondos, texto sobre oscuro |
| Rojo | `#ca3a36` | Acento, alertas, urgencia |

**Why:** El usuario compartió el PDF oficial de brand guidelines para que siempre use los colores correctos.
**How to apply:** Usar estos colores en cualquier template de email, componente UI o diseño visual de BodeParking. Los templates actuales usan variaciones (#1560A8, #1AB3E8) que se alejan del azul oficial #0091c3 — en próximos diseños ajustar a la paleta oficial.
